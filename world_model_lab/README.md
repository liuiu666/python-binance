# 轻量市场世界模型实验

本目录是独立、只读行情的研究实验，不接入 `server.js`、`auto_btc.js` 或任何实盘开关。

它不是完整的 LeCun 自主智能系统，也不是 JEPA 神经网络。第一版只验证一个可证伪的最小闭环：

```text
因果市场观测 → 潜在状态 → 未来状态/方向概率
                         ↓
               UP / DOWN / SKIP 动作价值
                         ↓
                  严格样本外回测
```

世界模型与普通分类器的区别在于：模型除方向外，还显式学习当前潜在状态到10分钟后潜在状态的转移；转移置信度和状态支持度只能降低交易边际，不能凭空制造交易信号。

## 数据

使用仓库中两份无缺口 BTCUSDT USD-M Futures 1分钟数据，合计3,458,880根，覆盖2020-01-01至2026-07-29。每10分钟只产生一个候选决策，结算窗口不重叠。

- 开发区间：2020-01-01至2026-01-31；前两年只作初始训练，walk-forward样本外预测从2022-01开始。
- 最终冻结集：2026-02-01至2026-07-29。
- 决策分钟收盘价作为入场价，10分钟后收盘价作为结算价。
- 1分钟数据不能声称精确模拟5秒UI执行延迟；现有短期秒级数据仅适合后续敏感性分析。

## 运行

```bash
python run_experiment.py
python -m unittest discover -s tests -t . -v
python run_frozen_holdout.py
```

必须先运行开发实验。它进行每月扩展窗口回测，记录全部预设 `min_ev` 候选，并写入：

- `reports/development_report.json`
- `reports/frozen_spec.json`
- `reports/development_predictions_*.csv`

`run_frozen_holdout.py` 只应执行一次。首次执行会创建 `reports/frozen_holdout_run.json`。再次执行默认拒绝；`--force` 可以技术性重跑，但报告会明确标记 `non_pristine`，不能再称为一次性未见验收。这个守卫用于研究纪律，并不是安全机制。

## 成功标准

冻结集必须同时满足：

- 世界模型胜率至少58%；
- 80%净赔付下PnL为正；
- 至少300笔实际交易；
- 多数月份PnL为正；
- 世界模型胜率和PnL都高于逻辑回归基线。

任一条件失败，结论就是“未达到目标”。不允许看过冻结结果后修改阈值、状态数或特征，再继续把同一时期称为未见数据。

## 局限

- 小资金动作不会显著改变BTC市场，因此动作主要改变账户结果，不改变市场转移。
- 潜在状态由可解释的分钟特征和MiniBatchKMeans得到，不是从原始数据自监督预训练的JEPA表征。
- 回测只证明历史统计表现，不能保证未来收益，也不能解决平台报价差异、拒单、延迟或出金风险。
- 若轻量模型在冻结集不优于逻辑回归，没有证据支持进入更昂贵的PyTorch/JEPA阶段。
