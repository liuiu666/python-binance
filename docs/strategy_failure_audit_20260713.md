# 2026-07-13 策略失效审计

## 结论

当前没有任何新策略通过严格样本外验证，不允许恢复实盘。

多周期迁移阶段 V1 的历史 `90 单 / 73.33%` 不是有效的独立结果。最终分支是在查看结果后选择，存在明显选择偏差。实际上线为 `8 单 / 12.5% / -62U`，最新本地未见数据复跑为 `10 单 / 30% / -46U`。

旧的动态正态/趋势订单薄 V2 在同一批最新数据、5 秒执行延迟下为 `2 单 / 0% / -10U`。因此不能简单切回旧版。

## 失效原因

1. 历史规则存在事后分组选择，漂亮结果被误标为独立验证。
2. 历史默认按信号后 2 秒入场，真实检测到下单平均约 9.72 秒。
3. 原历史信号中 39/90 的到期优势不超过 5bp，无法承受真实执行延迟。
4. 影子单使用信号价和信号时间，实盘使用平台数秒后的成交价，二者并非同一笔交易。
5. 因子关系发生行情切换。最新段过去 60 秒价格、成交流和盘口方向对未来 10 分钟的正确率分别只有 `32.8%`、`39.3%`、`37.7%`，固定顺势和固定回归都会失效。

## 已完成修复

- 历史加载保留完整秒轴，不再删除缺订单薄的秒后再计算时间窗口。
- 回测结算从实际入场时间起算 600 秒。
- 多周期迁移阶段 V1 在前端标记“历史回测已失效”。
- 影子单本地改为等待 5 秒，以等待结束时的市场价开仓，并从实际影子开仓时间起算 10 分钟。
- 实盘总开关和两个策略实盘开关保持关闭。
- 发现并修复5分钟外部数据时间泄漏：交易所时间戳是区间开始，历史回测和线上现在都必须等区间结束5分钟后才能使用。
- 影子单已部署为等待5秒后按当时市场价开仓，并从影子实际开仓时间起算10分钟。
- 已部署总持仓量、全市场账户多空比、顶级账户多空比采集；首次各回补500条且无错误。

## 冻结候选

四象限研究发现“过去5分钟上涨，同时15分钟总持仓增加，只做UP”在发现样本中为 `46单 / 63.04% / +31U / 回撤16U / 最大连亏3单`，且0/5/6/10秒入场结果一致。

该规则是在查看四象限结果后发现，属于研究选择，不能算验证。规则已在 `2026-07-13T03:45:00Z` 冻结，冻结前46单永久排除。只有冻结后至少50单达到 `>=60%`、盈利、回撤 `<=20U`、连亏 `<=3`，并且四种延迟全部盈利，才允许进入下一阶段。

冻结配置：`data/frozen_position_build_up_v1.json`。

### 冻结后早期结果与 V2 假设审计

截至 `2026-07-13 13:03`（上海时间），冻结后 V1 已到期信号为 `6 单 / 50% / -3U / 回撤 11U`。其中稳定胜单 2 笔、稳定亏损 3 笔、延迟敏感 1 笔；三笔稳定亏损在 0/5/6/10 秒四种执行延迟下均亏，因此当前主要矛盾是方向判断，不是执行延迟。

观察到部分亏损发生在短线价格、主动买盘和多头账户同时加速时。该观察发生在查看冻结后结果之后，只能生成新的研究假设，不能修改 V1，也不能把这 6 笔计入 V2 验证。

| 假设 | 总体 6 秒口径 | 前半段 | 后半段 | 结论 |

因此当前没有合格的 V2。研究脚本为 `py/research_position_build_up_v2.py`，结果为 `tmp/position_build_up_v2_discovery.json`；两者均与线上信号服务隔离。

## 恢复实盘门槛

新策略必须同时满足：

1. 研究段冻结规则后，不再修改参数。
2. 后续时间段至少 100 笔完全未见样本，胜率高于 60%，且分段均高于 55.56%。
3. 使用 5 秒执行延迟，结算从实际入场起算。
4. 最大回撤不超过 20U，最大连续亏损不超过 3 笔。
5. 线上与回测调用同一核心；影子与实盘使用同一成交时间和价格口径。
6. 先通过延迟影子单验证，再允许 5U 实盘；任何一项不达标都不启用。
