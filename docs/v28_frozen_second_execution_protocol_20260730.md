# V28 冻结主假设秒级执行验证协议（逐笔数据打开前冻结）

## 目的

V27 的主假设 H1 在2020–2023分钟数据上表现为“精确边界盈利、延后1分钟亏损”。V28不修改信号，使用同一批已经冻结的201笔信号，打开 Binance 官方逐笔聚合成交，判断0/5/10秒的真实执行延迟是否仍有优势。

本轮只验证执行，不允许根据逐笔结果改信号、方向、z阈值、状态门或持有期。

## 冻结信号

- 输入：[V27 H1交易清单](../tmp/v27_h1_direct_reversion_trades_20260730.csv)。
- 输入 SHA-256：`d3123884e02b743b24a81f61e23f130025bfb1c04ec2975714d2d99f2c56104a`。
- 时间：2020-01-01至2023-12-31。
- 信号数：201。
- 规则：`mid|revertible / w60 / z>=2.5 / DOWN / 10m`。
- 同族冷却：10分钟，V28不得增删信号。

## 数据

- Binance USD-M Futures BTCUSDT 官方日度 `aggTrades`。
- 每个日包必须校验官方 SHA-256。
- 只保留每个信号入场和结算目标附近的逐笔成交。
- 入场或结算成交的最大允许滞后为5秒；缺失必须报告，不能用分钟价格填补。

## 执行口径

延迟固定为0、5、10秒，并同时报告两种结算语义：

1. `entry_plus_600s`：从实际可成交入场tick起持有完整600秒；
2. `fixed_boundary`：无论入场延迟多少，都在原信号时刻后600秒结算。

所有延迟和语义必须使用共同覆盖的同一批信号。每笔5U，赢+4U、输-5U、平0U。

## 预注册通过门

主假设只有在两种结算语义、三个延迟全部满足时才通过：

- 共同覆盖不少于190笔；
- 胜率高于55.56%、PnL为正；
- Wilson 95%胜率下限高于55.56%；
- 2020、2021、2022、2023每年PnL均不为负，至少3年严格为正；
- 固定48个日历月至少60%盈利；
- 7日时间块bootstrap的90% EV下限大于0；
- 最大回撤不高于30U；
- 最长连亏不超过3笔。

任一核心条件失败即维持 `no_trade`。V28结果不得用于事后只选某个延迟或某个年份。
