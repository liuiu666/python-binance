# 2026-07-12 固定拍卖状态假设测试

研究脚本：`py/research_auction_state_hypotheses.py`。

这不是线上策略：它不扫描参数、不读取未来数据，也不修改任何线上配置。

## 固定口径

- 每秒判断状态；出现方向状态后锁定 600 秒。
- 信号后 2 秒入场，入场后 600 秒结算。
- 5U 单笔、80% 赔付。
- 状态定义固定为：平衡区回归、失败拍卖、价值区迁移、转换期。
- 使用三段不重叠的旧秒线与订单薄快照：7/5--7/6、7/8--7/9、7/10--7/11。

## 结果

结果只用于淘汰错误假设，不作为新策略上线依据。

| 状态 | 7/5--7/6 | 7/8--7/9 | 7/10--7/11 | 合计结论 |
| --- | --- | --- | --- | --- |
| 平衡区回归 | 14 单 / 64.29% / +11U | 29 单 / 62.07% / +17U | 60 单 / 56.67% / +6U | 103 单 / 59.22% / +34U，三段均为正，但后期优势偏薄 |
| 价值区迁移顺势 | 24 单 / 33.33% / -48U | 85 单 / 54.12% / -11U | 69 单 / 44.93% / -66U | 178 单 / 47.75% / -125U，明确淘汰 |
| 失败拍卖 | 1 单 / 0% | 1 单 / 100% | 1 单 / 100% | 仅 3 单，样本不足 |

## 结论

`价格在旧正态区外 + 5分钟价格同向 + 主动成交同向 + 盘口同向` 不等于新价值区被接受。
这个看似合理的顺势分支，在三段数据中均无法覆盖 80% 赔付下的盈亏线，常发生在冲刺尾部，
因此不能作为顺势开仓分支。

下一步由新逐笔成交和深度增量数据验证真正的接受：价格推进效率、被动流动性撤退/补回，
以及主动成交是否被吸收。只有这些状态在未参与调参的数据上重复成立，才会写进共享策略核心。
