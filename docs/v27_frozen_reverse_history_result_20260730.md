# V27 冻结规则反向历史验证结果（2026-07-30）

## 结论

两个冻结规则在此前完全未参与选择的2020–2023期货历史上都失败，最终决策均为 `no_trade`。

- 主假设 H1 在精确10分钟边界仍有正收益，但延后1分钟立刻转亏，固定原结算点几乎归零。
- 次假设 H2 在三种执行口径下全部明显亏损。
- 这说明此前2024–2026看到的优势存在强烈时间区间依赖和边界时点依赖，不能解释为稳定的低/中/高波动路由。
- 本轮参数与门槛在数据打开前已经冻结，没有根据2020–2023结果改方向、窗口、阈值或持有期。

## 对“正态是不是10分钟”的最终澄清

不是一个单一的“10分钟正态模型”：

- 波动状态窗口：120分钟；
- H1价格均值/标准差窗口：60分钟；
- H2趋势位移窗口：10分钟；
- 信号只在10分钟合约边界评估；
- 主持有/结算周期：10分钟；
- 秒级数据此前只用于验证入场延迟和真实逐笔结算，不负责计算上述分钟信号。

V27说明，问题的核心正是“精确边界”而不是统计窗口名称：H1从精确边界的+89U变成延后1分钟的-51U，优势无法转化为稳定执行。

## 决策

1. 中波动不能固定做直接回归，也不能固定做耗竭反转；当前空仓。
2. 高波动在V25中直接回归、确认反转和趋势延续均亏，耗竭反转样本无效；当前空仓。
3. 低波动长窗口回归只有区间性优势，跨年延后执行失败；当前空仓。
4. 不再用同一批历史继续扩大参数网格。若继续研究，应改变信息集，例如研究边界前后的逐笔路径、盘口/成交不平衡或新的独立市场，而不是继续微调z阈值。
5. 本轮未修改线上配置、影子单或实盘。
