# 2026-07-17 策略稳定性研究记录

## 目标

用本地所有可用的 BTC 秒级 K 线和订单薄数据，统一回放当前线上 V9 逻辑，定位拖累胜率和回撤的行情类型，并验证一个不依赖事后删单的改进版本。

## 数据范围

- 本地发现秒级数据 + 订单薄数据源：18 个
- 秒级和订单薄交集超过 6 小时的数据源：17 个
- 去重方式：先按 `time + signal + branch` 去掉重复快照，再对合并后的信号流执行同一个 10 分钟冷却
- 回测不是服务器回测，全部在本地数据上完成
- 每单金额按 5U，盈利按 +4U，亏损按 -5U

输出文件：

- `tmp/v9_all_usable_history_v11_z07_regime_core_20260717.json`
- `tmp/v9_all_usable_history_v11_z07_regime_core_20260717_trades.csv`
- `tmp/v9_all_usable_history_v11_annotated_20260717.csv`

## 当前 V9 的不稳定来源

V9 的问题不是单纯参数太松，而是两个分支混在一起后，坏行情会拖累整体：

1. 补充分支把“单边走势后的短反向分钟”当成衰竭回归，但价格有时并没有真正回到 600 秒正态极端附近。
2. 原始 V2 分支在成熟下跌、短周期上迁移后做 DOWN 这类状态里，历史表现明显拖累胜率和回撤。
3. 剩余亏损主要来自补充分支，尤其是成熟趋势里逆势抢回归，属于“拍卖还没结束就接反向”的问题。

## 已实现的共享核心改造

文件：

- `py/current_v2_augmented_v9_core.py`
- `py/backtest_online_strategies_latest.py`
- `py/signal_btc.py`

新增共享规则，默认关闭，不改变当前线上配置：

1. `v9SupplementMinAbsNormalZ`
   - 补充分支必须仍处在 600 秒正态分布的足够偏离位置。
   - 本次候选验证使用 `0.7`。

2. `v9OriginalRegimeVetoEnabled`
   - 原始 V2 分支启用行情状态否决。
   - 状态识别使用同一套共享函数，回测和线上一致。

3. 原始 V2 否决内容
   - 成熟下跌状态跳过原始 V2。
   - 短周期上迁移时，如果原始 V2 给 DOWN，跳过。

不是事后删亏单，而是在产生信号前使用共享逻辑。

## 剩余问题

V11 改善了稳定性，但还不能说完全稳定：

- 2026-07-09：8 单 / 50.00% / -4U
- 2026-07-15：4 单 / 50.00% / -2U
- 补充分支仍会在趋势拍卖未结束时逆势抢回归。
- 日均约 4.9 单，仍然偏少。

测试过“极端接飞刀保护”：

- 跳过补充分支 UP 且分钟级极端下跌的情况，可到约 53 单 / 71.7% / +77U。
- 但改善不大，继续加过滤会砍掉好单，收益下降。
- 因此暂不建议把这类小样本保护强行上线。

## 可执行建议

保守实盘方案：

- 上 V11 共享核心参数：
  - `v9SupplementMinAbsNormalZ = 0.7`
  - `v9OriginalRegimeVetoEnabled = true`
  - 保留 `v9OriginalVetoMatureDowntrend = true`
  - 保留 `v9OriginalVetoShortMigrationUpDown = true`
- 预期：胜率约 70%，回撤约 12U，日均约 5 单。

更稳但单更少的方案：

- 只跑原始 V2 分支，补充分支只做影子观察。
- 历史表现：22 单 / 77.27% / +43U，回撤更小，但日均约 2 单。

不建议：

- 为了把胜率拉到 75% 以上继续堆过滤。
- 目前这样会明显牺牲交易次数，且容易拟合最近几天。

## 追加研究：解决 V11 单数偏少

V11 的问题是日均只有约 4.9 单。继续研究后发现，V11 的 `0.7σ` 补充分支过滤太粗，会把一部分短周期有效回归也砍掉。

### 轻量探索结论

从 V9 被 V11 砍掉的 36 单里看：

- 被砍掉整体：36 单 / 52.78% / -9U，不应整体恢复。
- 补充分支里的短周期迁移反向单：10 单 / 70.00% / +13U，可以考虑恢复。
- 成熟上涨里的补充分支 DOWN，且 60 秒资金流不强空：6 单 / 83.33% / +15U，可以考虑恢复。
- 成熟下跌里的原始 V2 DOWN，如果 60 秒资金流明显偏空：2 单 / 100% / +8U，可以考虑恢复，但样本很小。

### V13 结论

V13 是当前更好的候选：

- 比 V11 多 12 单；
- 胜率从 70.37% 提到 72.73%；
- 收益从 +72U 提到 +102U；
- 最大回撤从 12U 降到 11U；
- 最大连亏仍是 2。

但它还不是“最终无风险版本”：

- 2026-07-13 和 2026-07-14 仍然只有 62%-64% 左右；
- 补充分支依然是主要风险来源；
- 新增的“成熟下跌顺势 DOWN”只有 2 单样本，不能过度相信。

更合理的下一步：

1. 把 V13 写成独立策略，不直接覆盖当前线上版本。
2. 先影子观察，确认线上信号数量和本地回测一致。
3. 如果要实盘，建议 5U 小额，不建议马上放大金额。
