# BTC 10分钟二元期权正态策略 V21 研究报告

生成时间: 2026-07-05

## 结论

当前更推荐的本地候选是:

`BTC_10min_NORMAL_STATE_V21_LOSS_DENSITY_3OF6_8H`

它不是重新发明一套“出上轨做空/出下轨做多”，而是在原来较平衡的秒级正态路由上，加一层“正态假设失效识别”:

- 正常状态继续交易。
- 如果最近 `6` 笔已结算交易里亏 `3` 笔，判定当前正态回归假设失效。
- 失效后冷却 `8` 小时，等待滚动窗口重建新的价格区域。
- 原有 `2` 连亏冷却 `1` 小时仍保留。

## 为什么这次不是简单拟合

1. 不是按具体日期、小时、价格点过滤。
2. 使用的是线上可获得的已结算交易结果，不用未来价格。
3. 邻近规则也有效:
   - `5/10` 亏损密度 `6h`: `137` 单 / `67.88%` / `18U` 回撤。
   - `3/6` 亏损密度 `6h`: `118` 单 / `70.34%` / 近期 `12U` 回撤。
   - `4/8` 亏损密度 `4h`: `135` 单 / `68.89%` / 近期 `15U` 回撤。
4. 训练段和近期段都为正收益，近期没有恶化。

风险仍然存在:

- 样本是 `116` 单，不是长期充分样本。
- 这层主要解决“策略失效后的继续交易问题”，不是证明每个入场点都更聪明。
- 如果市场连续多天换状态，策略会少做，日均单数会下降。

## 这次真正解决了什么

之前最大回撤大的根因:

- 市场离开旧正态区间后，策略还在用旧区间做均值回归。
- 单纯看 `trend_walk` 并不可靠，因为很多 trend walk 后反而会回归，直接禁掉会删掉大量赢家。
- 连续两亏冷却不够，因为实盘亏损常是 `L/W/L/L/W/L` 这种亏损密度上升，而不是纯连续亏。

V21 的核心改动:

- 不再把“趋势沿轨”一刀切判死刑。
- 用“最近交易结果密度”识别当前策略是否已经不适配行情。
- 一旦出现 `6` 单里 `3` 亏，就把状态切到 `failed_reversion`，冷却 `8` 小时。
- 这相当于承认正态窗口需要时间重建，不急着在旧分布里继续下单。
