# V35 秒级正态反转研究路径耗尽审计（2026-07-30）

## 结论

使用当前本地已有数据，目标中的历史研究要求已经得到完整覆盖，但“找出可稳定走步的秒级正态反转方案”仍被证据否定，不能标记完成。

当前唯一诚实的动作是三档波动全部 `no_trade`。继续在同一 BTC OHLCV 历史上修改 Z、波动窗口、结构阈值、成交量或影线门，会进一步增加选择偏差，不能产生新的独立证据。

本地也不存在足够长、连续且未按既有信号抽样的独立信息集。因此研究进入真实阻塞：需要新增多年连续的跨市场或微观结构历史，或者等待未来未触碰数据，才能继续推进稳定方案。

## 阻塞条件与解除方式

当前阻塞不是算力、代码或门槛太严格，而是没有新的独立纵向信息。以下任一项可以解除：

1. 至少两年连续 BTC 与 ETH/现货-期货跨市场分钟历史，用于只看过去的相对波动、基差和领先滞后路由；
2. 至少两年连续 BTC 主动买卖、持仓、资金费率或逐笔成交历史，不能只下载信号日；
3. 继续积累完全未参与特征设计的未来分钟与逐笔数据，达到预注册样本量后再验证；
4. 用户明确授权下载并冻结新的多年官方数据集，再开新协议。

在解除前，不再对同一历史追加阈值、方向、月份或OHLCV过滤器；不部署、不启用影子或实盘。
