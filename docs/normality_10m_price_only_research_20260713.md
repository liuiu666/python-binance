# 10分钟事件合约：价格-only 正态与支撑压力研究

## 口径

- 只使用秒级成交价格，不使用订单薄、主动成交、持仓量或账户比率。
- 正态窗口固定为过去 `600秒`，事件每 `60秒` 描述一次，执行延迟固定 `5秒`，到期从实际入场后 `600秒` 计算。
- 触边定义固定为滚动价格中心的 `|z| >= 1`；强触边为 `|z| >= 2`。
- `revert` 仅用于描述未来路径：触边后最终朝中心方向移动至少 `0.5σ`；`continue` 为反向移动至少 `0.5σ`；其余为 `flat`。
- 60秒事件之间有重叠，只能用于路径研究，不能当作下单回测。

## 当前结果

### 2026-07-10至07-11

- 上沿 `>=2σ`：`189` 个，回归 `40.21%`。

## 结论

1. 触及正态边界本身不是支撑或压力确认，回归概率低于一半，不能直接反向交易。
2. 上沿 `1.5～2σ` 在两个片段都偏向继续迁移，但不是单调 Z 关系，也还没有跨更多日期验证。
3. 下沿没有发现同样稳定的对称规律；不能因为上沿有现象就强行复制到下沿。
4. 回归路径通常不是一次瞬间反转。按未来路径拆分，真实回归样本前后两个五分钟段都朝中心移动；继续迁移样本前后两个五分钟段都远离中心。
5. 入场前的 Z 值和总斜率区分能力弱，下一阶段应检查速度减速、边界停留和触边次数的组合是否跨日期稳定。

## 价格-only 减速候选审计

固定规则：触边后最近 60 秒仍向外移动，但最近 10 秒相对最近 60 秒均速减速时，预测回归；没有减速时，预测继续迁移。事件之间强制间隔 600 秒，入场延迟 5 秒，结算从实际入场后 600 秒计算。

| 数据段 | 回归候选 | 继续候选 |
|---|---:|---:|
| 2026-07-05至07-06 | 20 单 / 40.00% / -28U | 9 单 / 22.22% / -27U |
| 2026-07-09至07-10 | 117 单 / 56.41% / +9U | 87 单 / 55.17% / -3U |
| 2026-07-10至07-11 | 118 单 / 60.17% / +49U | 74 单 / 59.46% / +26U |
| 冻结后当前片段 | 14 单 / 64.29% / +11U | 8 单 / 50.00% / -4U |

结论：减速方向在不同市场阶段不稳定，不能冻结为策略。脚本为 `py/research_price_only_deceleration_v1.py`，最新前向结果为 `tmp/price_only_deceleration_v1.json`。上述事件已按 600 秒去重，但历史段仍属于研究回放，不能替代新的盲测。

## 边界外持续时长审计

固定把同一侧边界外连续至少 `120秒` 定义为“旧价值区可能已被接受”，并分别测试上下沿顺势分支。结果仍不支持直接入场：

| 数据段 | 上沿成熟后做多 | 下沿成熟后做空 |
|---|---:|---:|
| 2026-07-09至07-10 | `8单 / 25.00% / -22U` | `5单 / 60.00% / +2U` |
| 2026-07-10至07-11 | `7单 / 42.86% / -8U` | `9单 / 55.56% / 0U` |
| 冻结后当前片段 | `2单 / 50.00% / -1U` | `0单` |

结论：边界外停留时间能识别“旧区间可能失效”，却不能证明未来 10 分钟继续同方向；成熟迁移阶段的顺势入场已经太晚。下一阶段研究首次越界后重新回到区间的时间和路径，不直接使用成熟状态下单。
