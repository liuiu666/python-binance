# 1至10分钟滚动正态形态研究

## 数据与口径

- 使用四段真实BTC秒级成交数据，合计约137.5小时。
- 每个完整分钟结束时，分别观察过去60、120、180直到600秒的价格分布。
- 研究对象是窗口内“价格所处位置的经验分布”，不是假设收益率严格服从正态分布。
- 每个周期统一计算中心、标准差、当前Z值、±1σ区内比例、偏度、峰度、中心位移、前后半段波动变化和路径效率。
- 形态分类只使用当时已经出现的数据。未来10分钟价格只用于事后验证。

固定形态包括：稳定钟形、中心上移、中心下移、波动扩张、波动收缩、上尾逃逸、下尾逃逸、左右偏、厚尾和畸变换区。

## 形态持续时间

- 1分钟中心上移/下移的中位持续时间都是1分钟，90%不超过3分钟。
- 5分钟中心上移持续2分钟、中心下移持续3分钟，90%不超过5分钟。
- 10分钟中心上移/下移的中位持续时间都是4分钟，90%不超过8分钟。
- 1至10分钟的稳定钟形中位持续时间都只有1分钟；10分钟稳定钟形90%不超过3分钟。
- 上下尾逃逸多数只显示1分钟，10分钟窗口下90%不超过3分钟。

因此“进入正态”不是一个长时间保持不变的开关。更常见的过程是中心移动、短暂形成钟形、再继续移动或逃逸。

## 形态转换

窗口越长，中心移动状态越有惯性：

- 1分钟上移下一分钟仍上移：35.57%；下移仍下移：35.95%。
- 2分钟上移仍上移：43.12%；下移仍下移：43.05%。
- 5分钟上移仍上移：63.62%；下移仍下移：66.36%。
- 10分钟上移仍上移：77.38%；下移仍下移：78.37%。

尾部逃逸通常不是立即回到旧中心，而是旧中心追上价格并形成新区间：

- 2分钟上尾逃逸后转成中心上移：75.42%；下尾逃逸后转成中心下移：80.64%。
- 5分钟上尾转上移：75.64%；下尾转下移：78.38%。
- 10分钟上尾转上移：59.87%；下尾转下移：62.25%。
- 新10分钟中心上移中，前一分钟是上尾逃逸的占58.3%；新中心下移中，前一分钟是下尾逃逸的占55.3%。

形成10分钟上尾逃逸之前，同一时刻1分钟已上移占73.0%，2分钟上移或已上尾占97.2%，5分钟已上尾占74.8%。下尾逃逸具有对称结构。

形成新的10分钟中心上移时，5分钟已经上移占84.8%，3分钟已上移占73.7%，2分钟已上移占49.7%；1分钟当时反而经常出现短暂反向波动。因此识别新区间不能只看最后1分钟。

## 对未来10分钟的验证

仅凭价格分布形态没有达到稳定可交易优势：

- 所有周期尾部回归率约50%至54%。
- 10分钟上下逃逸后的回归率：历史54.40%，最新段54.80%，低于80%赔付所需55.56%。
- 10分钟中心移动后的顺势率：历史49.29%，最新段48.42%。
- 10分钟稳定钟形尾部回归在四段分别为58.49%、72.97%、42.86%、56.00%，分段极不稳定。

稳定钟形、尾部位置或中心斜率都不是单独可用的方向信号。它们能描述拍卖阶段，但要判断回归还是换区，仍需主动成交后的价格进展、近价位挂单增减、吸收和流动性真空确认。

## 可执行结论

1. 1分钟适合检测变化速度，但噪声大，方向每分钟翻转很多。
2. 2至3分钟适合观察短期形态是否开始一致，但不能独立决定10分钟方向。
3. 5分钟是新区间形成的较早确认层：10分钟刚转为上移/下移时，5分钟通常已经同向。
4. 10分钟适合定义当前价值区和中心迁移状态，但尾部本身不能直接做反转。
5. 后续策略应识别“1/2/3分钟先启动、5分钟确认、10分钟尚在旧区”的换区过程，再用订单流判断跟随还是衰竭，而不是寻找某一个最佳正态窗口。
