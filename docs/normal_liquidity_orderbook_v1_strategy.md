# 正态流动性订单薄 V1 策略

## 定位

这个策略不是单纯正态分布，也不是画线支撑压力。

它只交易一种场景：

1. 市场已经重新进入短周期正态震荡。
2. 价格刚刚假突破正态边界。
3. 价格回到正态区间内。
4. 订单薄显示对应方向的被动支撑/压力仍然存在。
5. 主动成交没有形成真突破。

因此它是一个“假突破回归”策略，不是趋势突破策略。

## 数据要求

必须同时有：

- 秒级成交 K 线
- 秒级订单薄特征

如果订单薄缺失、延迟、或异常，本策略不下单。

不要降级成只靠正态分布交易。原因：本地长样本测试显示，无订单薄版本在 2026-06-13 到 2026-07-06 期间为 `348单 / 54.89% / -21U / 最大回撤110U`，不可实盘。

## 正态区间

滚动窗口：`600秒`

中心线：

```text
优先 VWAP = sum(price * volume) / sum(volume)
如果成交量不可用，退回滚动均价
```

标准差：

```text
优先成交量加权标准差
如果不可用，退回普通标准差
```

正态带：

```text
上轨 = center + 1σ
下轨 = center - 1σ
```

## 进入正态的条件

只有满足以下条件，才允许找信号：

```text
秒级覆盖率 >= 88%
最近600秒处于 ±1σ 内的比例 >= 55%
中心线最近300秒斜率绝对值 <= 8bp
sigma 在 5bp 到 55bp 之间
sigma 扩张倍率 <= 1.9
```

含义：

- 不是大单边。
- 不是极低波动假死。
- 不是突发行情扩张中。
- 价格已经开始围绕中心线震荡。

## 做多条件

```text
过去120秒内，价格曾跌破 -1.2σ
现在价格回到 -0.85σ 到 0σ 之间
订单薄 bid 侧有被动支撑：
  imbalance_20 >= 0.08
  microprice_edge_bps >= 0.001
  bid_qty_20 >= ask_qty_20
  bid_qty_20 最近30秒没有大幅撤单
主动卖出没有形成真跌破：
  flow_60 > -0.28
```

触发方向：`UP`

## 做空条件

```text
过去120秒内，价格曾突破 +1.2σ
现在价格回到 0σ 到 +0.85σ 之间
订单薄 ask 侧有被动压力：
  imbalance_20 <= -0.08
  microprice_edge_bps <= -0.001
  ask_qty_20 >= bid_qty_20
  ask_qty_20 最近30秒没有大幅撤单
主动买入没有形成真突破：
  flow_60 < 0.28
```

触发方向：`DOWN`

## 执行规则

```text
周期：10分钟二元期权
下单金额：先固定 5U
同策略最小间隔：600秒
同策略不重叠持仓
订单薄延迟超过 3秒：不交易
秒级覆盖率低于 88%：不交易
```

## 本地验证

### 有订单薄样本

数据范围：

```text
2026-07-05 13:04:45 到 2026-07-06 21:32:05 北京时间
共 32.46小时
订单薄缺口约 1.57%
秒级 observed 约 91.67%
```

最佳参数：

```text
NL_OB_RECLAIM_W600_Z120_OB8_IN55
```

结果：

| 范围 | 单数 | 胜率 | 盈亏 | 最大连亏 | 最大回撤 |
|---|---:|---:|---:|---:|---:|
| 全部32.46小时 | 20 | 65.00% | +17U | 2 | 13U |
| 7/6前向测试 | 9 | 66.67% | +9U | 1 | 5U |

同区间 V21：

| 策略 | 单数 | 胜率 | 盈亏 | 最大回撤 |
|---|---:|---:|---:|---:|
| V21 | 12 | 58.33% | +3U | 7U |
| 本策略 | 20 | 65.00% | +17U | 13U |

### 无订单薄对照

同一正态假突破逻辑，去掉订单薄后：

| 数据 | 单数 | 胜率 | 盈亏 | 最大回撤 |
|---|---:|---:|---:|---:|
| 6/13-6/17 固定参数 | 73 | 54.79% | -5U | 57U |
| 6/13-7/6 固定参数 | 348 | 54.89% | -21U | 110U |
| 7/5-7/6 同区间固定参数 | 24 | 58.33% | +6U | 19U |

结论：订单薄不是锦上添花，是这个策略的硬条件。

## 当前建议

不要直接实盘。

可执行路径：

1. 作为影子策略上线。
2. 至少收集 5 到 7 天订单薄样本。
3. 每天统计：
   - 单数
   - 胜率
   - 最大连亏
   - 最大回撤
   - 上假突破回归 vs 下假突破回归
4. 如果连续样本仍然满足：
   - 胜率 >= 62%
   - 每天 >= 8单
   - 最大连亏 <= 2
   - 单日最大回撤 <= 10U
   才考虑小金额实盘。
