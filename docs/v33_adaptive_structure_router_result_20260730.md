## 研究判断

1. V32 证明绝对结构门过硬；V33 证明把结构门改成自适应后仍没有优势。两者合起来否决了“只是指标写死导致上线亏损”的解释。
2. 当前价格型策略族的主要问题是边界优势不可执行、年份漂移和动作本身缺乏稳定性，而不是再换一个波动/趋势分类阈值。
3. 不应继续在同一 OHLC 价格特征上扩大 Z、分位或结构网格。下一项研究必须引入未使用的信息，例如分钟成交量、振幅、实体/影线与价格冲击之间的吸收关系，并在运行前冻结少量规则。
4. V33 的设计发生在 V32 全历史结果打开以后，所以即便曾通过也不能视为全新留出证据；本轮实际完全未通过，更不能部署。
