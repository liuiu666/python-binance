# V29 秒级 Reclaim 确认走步结果（2026-07-30）

## 结论

冻结的5秒价格回收确认没有形成跨时间区间稳定性，最终仍为 `no_trade`。

- 规则：分钟主信号保持 `mid|revertible / w60 / z>=2.5 / DOWN`；信号后5秒价格不高于信号时价格才入场。
- 入场：确认后额外0/5/10秒，即原信号后5/10/15秒。
- 结算：同时测试实际入场后600秒、固定原10分钟边界。
- 298笔冻结分钟信号、266个官方逐笔成交日期均获得因果执行解析。

## 主规则分区结果

### 2020–2022开发诊断

146笔原信号中85笔通过确认。六种执行组合中只有固定边界、确认后立即入场为正（+12U）；其余为-6U至-29U。最大回撤41–69U，说明规则在早期历史没有形成稳定优势。

### 2023主时间测试

55笔原信号中33笔通过确认：

| 结算语义 | 确认后0秒 | 确认后5秒 | 确认后10秒 |
|---|---:|---:|---:|
| 入场后600秒 | 54.55% / -3U | 54.55% / -3U | 63.64% / +24U |
| 固定原边界 | 57.58% / +6U | 57.58% / +6U | 57.58% / +6U |

六档没有全部为正，因此主测试直接失败；不能事后只保留确认后10秒。

### 2024–2025重用验证

74笔原信号中46笔通过确认，六档均盈利：

- 入场后600秒：+67U / +40U / +40U；
- 固定原边界：+76U / +67U / +45U。

但2025年“入场后600秒、确认后5秒”单年为-1U，且该区间已经参与旧信号研究，不能覆盖早期失败。

### 2026重用诊断

23笔原信号中14笔通过确认，六档为+11U至+20U，但样本过小。

## 2023–2026合并诊断

共同确认93笔：六档合并PnL均为正（+57U至+93U），但仍未通过：

- Wilson 95%下限只有固定边界、确认后立即入场达到55.56%以上；
- 2023的实际入场+600秒0/5秒两档均为-3U；
- 2025其中一档为-1U；
- 多个口径最大回撤超过25U或最长连亏达到4笔。

## 邻域否决

- 5秒阈值-1bp：2020–2022和2023多数口径亏损；
- 5秒阈值+1bp：2023六档全部非正；
- 10秒、0bp确认：2020–2022两种语义均亏，2023实际入场+600秒为-14U。

后期盈利不是稳定阈值平台。

## 决策

价格路径确认能够改善2024以后结果，但不能修复2020–2023的结构漂移。V29不晋级影子候选，不部署、不启用实盘。
