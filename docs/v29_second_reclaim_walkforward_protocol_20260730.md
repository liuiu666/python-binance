# V29 秒级 Reclaim 确认走步协议（确认特征计算前冻结）

## 失败机制与唯一主改动

V28 的冻结主信号在0秒为正、5秒显著衰减、10秒转负。V29不改分钟波动、结构、窗口、阈值、方向或持有期，只测试一个事先定义的因果确认：前5秒价格已经停止向不利方向延伸并开始回收，才允许入场。

## 冻结分钟信号

- `mid|revertible / w60 / z>=2.5 / DOWN / 10m`。
- 信号集合来自V27/V28及相同规则在2024–2026的冻结复算。
- 不允许改成UP、删除亏损年份或重新搜索分钟参数。

## 主确认规则

对每个DOWN信号：

1. `p0`：信号时刻第一笔可成交价；
2. `p5`：信号时刻后5秒第一笔可成交价；
3. 仅当 `p5 <= p0` 时通过确认；否则空仓；
4. 确认完成后测试额外0/5/10秒执行延迟，即总入场时刻为信号后5/10/15秒。

最大tick滞后5秒；缺价格直接记缺失，不用分钟价填补。

## 两种结算语义

- `entry_plus_600s`：从实际入场tick起完整持有600秒；
- `fixed_boundary`：仍在原信号时刻后600秒结算。

六个执行组合必须使用共同覆盖信号并全部报告。

## 时间分区

- 2020–2022：开发诊断，只判断主规则是否完全无效，不用于调阈值；
- 2023：主时间顺序测试；
- 2024–2025：信号规则已参与旧研究，标为重用验证；
- 2026：重用诊断。

确认规则在任何分区结果计算前已冻结。由于分钟信号本身已使用后期历史选择，V29仍不能宣称拥有完全未污染的最终样本外。

## 邻域否决规则

只作鲁棒性否决，不得反向选择：

- 5秒价格变化不高于 `-1bp / 0bp / +1bp`；
- 10秒价格变化不高于0bp。

主结果始终是5秒、0bp规则。邻域若普遍翻负，主规则不得晋级。

## 通过门

主规则晋级为新的历史候选必须同时满足：

1. 2023主测试两种结算语义、三种执行延迟全部PnL为正；
2. 2024–2025重用验证六档全部PnL为正；
3. 2023–2026共同测试信号不少于60笔；
4. 共同测试六档胜率均高于55.56%、PnL为正，Wilson 95%下限均高于55.56%；
5. 有交易的年份中至少3年六档均为正；
6. 7日块bootstrap 90% EV下限六档均大于0；
7. 六档最大回撤不高于25U、最长连亏不超过3笔；
8. 相邻阈值与10秒确认不得出现大范围负收益平台。

任一核心门失败即维持 `no_trade`，不能事后只保留某个延迟或结算语义。

## 安全边界

- 只做本地历史研究；
- 不部署、不更新影子路由、不启用实盘。
