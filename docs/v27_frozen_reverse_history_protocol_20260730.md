# V27 反向历史验证冻结协议（数据打开前冻结）

## 目的

使用此前未参与 V14–V26 选择的 Binance USD-M Futures BTCUSDT 2020-01-01 至 2023-12-31 一分钟数据，验证两个已经冻结的低频规则。该区间只能用于验证，不能根据结果改参数或换方向。

这是反向时间历史验证，不是未来样本，也不能被表述为实盘证明。

## 数据冻结

- 市场：Binance USD-M Futures BTCUSDT。
- 粒度：1分钟K线。
- 区间：`2020-01-01T00:00:00Z <= open_time < 2024-01-01T00:00:00Z`。
- 来源：Binance 官方 `data.binance.vision` 月度K线归档，并逐包校验官方 SHA-256。
- 下载完成后记录合并文件 SHA-256、行数、缺口、重复和首尾时间。
- 不允许把现货与期货收益标签混合。

## 冻结主假设 H1

此前 V22–V24 的直接均值回归候选，参数保持不变：

- 波动识别：120分钟实现波动；此前7天因果滚动33%/67%分位；仅 `mid`。
- 结构：仅 `revertible`；`ER60 <= 0.30`、`|M60| <= 1.50`、半衰期3–30分钟、ADF式 `t <= -2.5`、`VR10 <= 0.90`，且过去10分钟无 `shock >= 1.60`。
- 局部价格标准化：`w60`。
- 入场：`z >= 2.5` 时只做 `DOWN`。
- 主持有期：10分钟。
- 信号边界/同族冷却：10分钟。
- 不测试或改成 UP，不根据 V27 改 z、窗口或结构阈值。

## 三种执行口径

每个假设必须在完全相同的信号集合上同时报告：

1. 精确边界入场，持有10分钟；
2. 延后1分钟入场，再完整持有10分钟；
3. 延后1分钟入场，但固定在原10分钟结算点。

每笔5U，赢+4U、输-5U、平0U。

## 预注册通过门

主假设 H1 只有在三种执行口径全部满足时才通过：

- 已决交易不少于100笔；
- 胜率高于55.56%、累计PnL为正；
- Wilson 95%胜率下限高于55.56%；
- 2020、2021、2022、2023每年PnL均不为负，且至少3年严格为正；
- 固定日历月（包括无交易月）至少60%盈利；
- 7日时间块 bootstrap 的90% EV下限大于0；
- 最大回撤不高于30U，最长连亏不超过3笔。

任一核心条件失败即输出 `no_trade`；不允许为了过门删除月份、改方向、改窗口、改阈值或换持有期。
