# V14 秒级反转稳定性研究结果（2026-07-29）

## 结论

`V14-Core`、`V14-Robust`、`V14-Regime` 均未通过预先锁定的历史稳定性筛选，不部署任何 V14 候选，也不创建新的影子采样纪元。真实交易继续禁止。

这不是因为样本数不足而暂缓判断：三个候选分别有 93、108、81 个冷却后独立机会，但基线期望均为负，参数邻域也没有形成稳定盈利平台。

## 数据与统一口径

- 发现 19 组成交/订单簿历史快照；2 组为完全重复文件，实际加载 17 组唯一文件对。
- 唯一精确配对秒：978,050。
- 数据分为 5 个因果连续段，覆盖 2026-07-05 至 2026-07-16，以及 2026-07-28 至 2026-07-29。
- 2026-07-17 至 2026-07-27 没有完整成对订单簿证据，未伪造或补成有效样本。
- 信号、入场和结算全部使用 Binance Futures。
- 0/5/10/15 秒档实际从信号后的第 1/6/11/16 秒开始寻找首个期货 tick；到期从实际入场再加 600 秒。
- 所有候选共享 600 秒同族冷却；重复快照和重复候选不会增加交易数。
- 收益口径为 5U、胜 +4U、负 -5U；盈亏平衡胜率为 55.56%。

## 稳定性失败证据

### 参数邻域

- Core：57 个版本中仅 1 个版本在四档延迟均为正，比例 1.75%。
- Robust：57 个版本中 0 个四档均为正。
- Regime：61 个版本中 0 个四档均为正。

Core 唯一四档为正的是 `z_reclaim -20%`，最低 PnL 仅 +3U、最低胜率 55.95%，且相邻绝大多数版本为负。这是孤立点，不是可晋级的参数平台。

### 方向与时段

- Core 5 秒档：DOWN 40 单、57.50%、+7U；UP 53 单、52.83%、-13U，收益依赖单一方向。
- Core 最差交易日为 2026-07-09：17 单、35.29%、-31U、最大八连负。
- Robust 的 UP 方向为 59 单、40.68%、-79U，是主要亏损来源。
- Regime 的两个方向在 5 秒档均为负收益。
- Core 在 7 月 28–29 日审计窗口为 7 单、4胜3负、+1U，但旧开发窗口 86 单只有 54.65%、-7U；7 单不能覆盖整体失败。

## V13 参考

在 7 月 28–29 日生产快照上，旧 V13 参考为 7 单、4胜3负、57.14%、+1U，最大回撤 15U、最大三连负。该窗口太小，且 V13 已被真正前向结果和伪冻结问题否决，不能据此恢复实盘。

## 决策

- V14 三个候选全部拒绝。
- 不部署 V14 影子版本，不修改线上配置。
- `realTradingAllowed=false`。
- 不以某个单点参数或某个盈利日期包装成“稳定模型”。
- 若继续研究，应创建结构不同的 V15 假设；本次结果只能作为诊断依据，不能在同一数据上继续反复筛选后宣称样本外有效。
