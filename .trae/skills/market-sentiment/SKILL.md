# 大盘情绪技能

此技能用于判断大盘是否处于可交易环境，避免在系统性风险中开仓。

## 风险判断
1. 1h 大幅下跌直接熔断
2. 4h 趋势与 1h 背离时降低风险偏好
3. 资金费率与持仓量异常时降低交易频率

## 需要的数据
- BTC 与 ETH 的 1h 与 4h K 线
- 资金费率与持仓量变化
- 24h 波动与价差

## 输出结构
必须输出 JSON，字段如下：
- is_safe: YES 或 NO
- risk_level: 低 中 高
- reason: 一句话理由

## 提示词模板
请以专业币圈交易员身份给出大盘风险判断，只输出 JSON：
{
  "is_safe": "YES/NO",
  "risk_level": "低/中/高",
  "reason": "一句话理由"
}
